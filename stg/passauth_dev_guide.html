개발자센터 기능 소개

PASS 개발자센터의 주요 기능을 안내합니다.

1. 사전 준비 가이드

연동 전 필수 사전 준비 사항을 안내합니다

  1. SETP 01

    상단 메뉴의 '가이드' 메뉴를 클릭합니다.

  2. SETP 02

    좌측 사이드바에서 '연동하기' 하단 '사전 준비' 메뉴를 클릭하여 세부 항목을 확인합니다.

  3. SETP 03

    순서대로 도메인 설정, 키 발급, 토큰 발급을 진행합니다.

    도메인 및 방화벽 설정

    PASS 인증서 연동에 필요한 서비스 도메인 설정 방법에 대해 안내합니다.

    API 접근 토큰 및 키 발급 요청

    API 연동에 필요한 암호화 키 발급 방법을 안내합니다.

    도메인 및 방화벽 설정

    서비스 도메인 등록과 방화벽 설정 방법을 안내합니다.

    API 접근 토큰 및 키 발급 요청

    API 연동에 필요한 암호화 키 발급 방법을 안내합니다.

  4. SETP 04

    각 단계별 가이드를 참고하여 설정을 완료합니다.
